# Phase 6 Step 6-3 개발 지침 — 3D 건물 데이터 타당성 검증

## 목적

제품 코드를 수정하지 않고 외부 3D 건물 데이터의 도입 가능성을 `ADOPT`, `HOLD`, `REJECT` 중 하나로 판정한다.

## 허용 범위

- 후보: Overture Maps Buildings, 국내 공공 건축물 공간정보 또는 합법적으로 재배포 가능한 벡터 타일
- 표본 지역: 광진구, 강남구, 제주도 도심 표본
- 신규 조사 문서, 측정 스크립트, 임시 표본 데이터만 추가 가능

## 금지 범위

- `frontend/src/**`, `src/**`, 운영 DB, 기존 수집기 수정 금지
- 출처·라이선스·비용이 확정되지 않은 데이터를 제품에 연결 금지
- 건물 높이 결측치를 실제 높이처럼 단정하거나 임의 보간 금지
- 새로운 렌더링 의존성 추가 금지

## 필수 검증

1. 대한민국 커버리지와 높이/층수 결측률
2. WGS84 변환 후 기존 점포 좌표와의 공간 정합성
3. 라이선스의 가공·저장·재배포·화면 표시 허용 범위
4. 전국 저장 용량, 갱신 주기, 호스팅·전송 비용
5. 세 표본 지역의 위치 오차와 높이 결측 실측
6. 격자·점포·건물 동시 표출 시 데스크톱 45fps, 모바일 30fps 가능성

## 산출물

- 후보별 출처와 라이선스 근거 링크
- 동일 표본 범위의 정량 비교표
- 비용과 운영 복잡도
- 데이터 품질·법적·성능 위험
- 최종 판정 `ADOPT | HOLD | REJECT` 및 근거

## 완료 조건

근거가 재현 가능하고, 결측·비용·라이선스가 숫자로 명시되며, 제품 코드 변경 없이 판정 보고서를 제출하면 완료한다. `ADOPT`일 때만 별도 사용자 승인 후 Step 6-4 구현 계획을 작성한다.
