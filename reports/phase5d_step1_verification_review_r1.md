## 4. 추가 확인 사항

현재 패널에는 `공정위 공식 가맹사업 거시통계 (전국 가맹본부 기준)` 및 `개별 매장 실측치 아님` 문구가 존재한다. 그러나 이는 다음 이유로 R2 인수 기준을 자동 충족하지 않는다.

- `개별 매장 실측치 아님`은 `특정 브랜드 실적 아님`과 의미가 다르다.
- 실제 브랜드 선택 시 화면 전체 맥락에서 브랜드 귀속으로 오인되는지 검증하지 않았다.
- 모바일 접힘 상태에서 핵심 안내가 첫 화면에 보이는지 증빙이 없다.
- 지역 선택 상태에서 전국 모집단 안내가 충분한지 사용자 흐름 기준으로 확인하지 않았다.

## 5. 필요한 재작업

1. 전년비 UI 구현을 계속 진행하지 않는다.
2. R2 Step 5D-1의 감사만 수행한다.
3. 최소 시나리오는 다음을 포함한다.
   - 전국 + 전체 업종
   - 시군구 + 특정 업종
   - 실제 브랜드(메가커피) 선택 가능 경로
   - 데스크톱 1440×900
   - 모바일 390×844
4. 각 시나리오에서 제목, 출처, 모집단, 브랜드 비귀속, 연도 상태의 실제 텍스트와 화면 위치를 기록한다.
