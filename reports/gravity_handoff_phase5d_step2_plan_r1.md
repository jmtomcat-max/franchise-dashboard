## 2. 이번 작업 목표

공정위 전국 업종 벤치마크가 특정 브랜드 또는 선택 지역의 실적으로 오인되지 않도록 하는 **Step 5D-2 최소 수정계획서**를 작성한다.

## 3. 계획에 포함할 필수 수정

### 데스크톱 및 공통

1. 대표 라벨을 `전국 가맹본부 대표매출 (중앙값)`처럼 전국 범위가 직접 드러나도록 변경한다.
2. 히어로 근처 첫 화면에 다음 의미의 짧은 안내를 상시 노출한다.
   - 전국 선택 업종의 거시 참고 기준
   - 특정 브랜드 또는 개별 점포의 실적이 아님
3. 2026년 선택 시 다음 내용을 호버 없이 인라인으로 표시한다.
   - 진행형 스냅샷
   - 약 30% 미등록 결손
   - 2025년과 직접 비교 불가

### 모바일

1. 공정위 버튼을 눌러 열린 축소 피크 바에 다음 세 의미를 포함한다.
   - 공정위
   - 전국
   - 업종 참고치
2. 43px 높이에서 과도한 문장을 넣지 않는다.
3. 확장 패널 첫 화면에 출처·전국 모집단·브랜드 비귀속 안내를 콤팩트하게 배치한다.
4. 기존 닫기, 축소/확장, 스크롤, 44px 터치 기준을 유지한다.

## 4. 명시적 제외

다음은 수정계획에 포함하지 마라.

- 좌측 패널 높이를 늘려 Top 5를 기본 노출하는 작업
- 좌측 Top 5와 FTC 패널을 억지로 같은 화면에 배치하는 작업
- 모바일 FTC 패널 자동 열기
- 모바일 초기 수납 구조 제거
- 공정위 버튼의 불필요한 확대 또는 새 내비게이션 추가
- 전년비 UI 구현
- 백엔드 API 또는 DB 변경
- 새 의존성 추가
- 브랜드명과 공정위 가명 레코드 결합

## 7. 인수 기준

- 데스크톱 히어로에 `전국` 의미가 실제 노출된다.
- 첫 화면에 `특정 브랜드/개별 점포 실적 아님` 의미가 실제 노출된다.
- 모바일 피크에 `공정위`, `전국`, `업종 참고치`가 포함된다.
- 모바일 확장 첫 화면에 출처와 비귀속 안내가 보인다.
- 2026 스냅샷 제한이 호버 없이 보인다.
- 모바일 초기 수납과 지도 비차폐가 유지된다.
- 좌측 패널과 Top 5 레이아웃은 변경하지 않는다.
- API·DB·보호 파일 변경 0건이다.
- 원시 JSON, PNG, 실행보고서, 품질보고서 판정이 일치한다.
