### 1.2 백엔드 API (FastAPI) 현황
1. **100m 밀집도 격자 조회 (`/api/v1/spatial/density/grid`)**:
   - `sigungu_code` (str, 5자리), `sido_code` (str, 2자리), `min_stores` (기본 3), `limit` (기본 1000, 최대 5000) 파라미터 완전 지원.
   - 전국 256개 시군구 코드를 넘기면 해당 시군구의 격자를 즉시 필터링하여 GeoJSON 호환 객체로 반환.
2. **지역 목록 및 상세 분석 (`/api/v1/analytics/regions`, `/api/v1/analytics/regions/{region_code}`)**:
   - 16개 시도 및 256개 시군구의 총점포수, 가맹점수, 브랜드점포수, 침투율, 면적당 점포밀집도, 상위 10개 브랜드 서빙 완료.
3. **공정위 거시통계 API (`/api/v1/ftc/*`)**:
   - `/status`: `latest_benchmark_year`("2026"), `financial_year`("2025"), `is_snapshot`(true), 수집일시 반환.
   - `/benchmark/latest`: 원자적 직전 연도 대체(Atomic Fallback), 8대 업종별 대표매출 중앙값, 5% 절사평균, 가중평균, 창업비용 구성 서빙.
   - `/trends`: 4개년 연도별 표본수, 가맹점수 합계, 직영점수 합계 서빙.
   - `/years`: 이용 가능한 4개년 목록 반환.

### 1.3 프론트엔드 대시보드 (React + MapLibre GL JS) 현재 상태
1. **지도 렌더링 계층**:
   - 타일 렌더러: **MapLibre GL JS + OpenStreetMap (OSM) 표준 래스터 타일 (`https://tile.openstreetmap.org/{z}/{x}/{y}.png`)**.
   - 공간 레이어: GeoJSON Source (`density-grid-source`) 기반 원형 격자 레이어 (`type: 'circle'`, `density-grid-circles`).
2. **현재 프론트엔드의 격자 호출 상태와 한계**:
   - `api.js`의 `fetchGridDensity(sigunguCode = '11215')`에 `limit=1000`이 고정되어 있음.
   - 기본 상태에서 광진구(`11215`) 격자(466개)만 호출하고 있어, 타 지역의 실제 격자(256개 시군구, 76,745개)를 사용자에게 보여주지 못하고 있었음.
   - 제주시(`50110`)는 실제 1,351개 격자를 보유하고 있어 `limit=1000` 기본값 적용 시 351개 격자가 누락(잘림)되는 문제가 있음.

   - *우리 프로젝트 적용 (정정)*:
     - 광진구에 국한되지 않고, 사용자가 16개 시도 및 256개 시군구(예: 강남구, 제주시, 해운대구, 분당구 등)를 선택하면:
       1) 백엔드 `/api/v1/analytics/regions/{region_code}`를 통해 해당 시군구의 총 점포수, 침투율, 지역 내 상위 브랜드 Top 5 표시.
       2) 백엔드 `/api/v1/spatial/density/grid?sigungu_code={sigungu_code}&limit=1500`를 통해 해당 시군구의 **실제 100m 밀집도 격자를 즉시 조회하여 지도 레이어 교체**.
       3) 지도 카메라가 해당 시군구의 중심 좌표로 부드럽게 이동 (`map.flyTo`).

   - *레퍼런스 방식*: 개별 매장/디스트릭트 실적을 전체 평균/중앙값 기준선과 대비.
   - *우리 프로젝트 적용 (침투율 정정)*:
     - 선택한 시군구의 **공식 가맹점 침투율**을 전국 공식 기준선(**6.53%**)과 비교하고, **브랜드 연계 침투율**을 전국 브랜드 기준선(**22.89%**)과 독립적으로 비교하는 듀얼 게이지 바 배치.
     - 가상 수치(26.2%)를 완전히 배제하고 분자/분모를 명확히 분리 표출.
   - *상태*: `즉시 적용 가능`
3. **지역별 외식업 규모 및 침투율 랭킹 (Regional Rankings)**:

     - 백엔드 `/api/v1/analytics/regions`를 활용하여 전국 256개 시군구의 "외식업 점포수 상위 지역 Top 5" 및 "가맹점 침투율 상위 지역 Top 5" 요약 테이블 제공.

   - *레퍼런스 방식*: 당해년도(TY)와 전년도(LY) 실적 편차($\Delta$) 및 편차율($\%$) 분석.

### 5.2 전년 대비 가맹점수 및 매출 지표 정의와 모집단 한계 판정

#### A. 지표 집계 단위 및 수식 구분

1. **유형 1: 단면 거시 시계열 편차 (Cross-sectional Macro Trends)**:
   - **집계 단위**: 8대 대분류 업종 전체 (해당 연도에 공정위에 등록된 모든 브랜드 모수).
   - **매출 중앙값 편차 수식**:
     $$\Delta \text{Median Sales} = \text{Median}_{t}(\{s_i\}_{i \in B_t}) - \text{Median}_{t-1}(\{s_j\}_{j \in B_{t-1}})$$
     *(여기서 $B_t$는 $t$년도 양수 매출 공시 브랜드 집합, $s$는 브랜드별 평균 매출액 `avg_sls_amt`)*
   - **총 가맹점수 편차 수식**:
     $$\Delta \text{Total Franchise Stores} = \sum_{i \in B_t} \text{frcs\_cnt}_i - \sum_{j \in B_{t-1}} \text{frcs\_cnt}_j$$
   - **주의**: 이는 두 독립된 연도별 횡단면 집합의 통계치 차이이며, 개별 브랜드별 전년 차이의 평균이 아님.

2. **유형 2: 개별 브랜드 자가보고 전년비 (Brand-level Within-Record YoY)**:
   - **집계 단위**: 단일 브랜드 레코드 (`ftc_brand_macro_records`).
   - **가맹점수 변동 수식**:
     $$\Delta \text{frcs}_i = \text{frcs\_cnt}_i - \text{prvyr\_frcs\_cnt}_i$$
   - **매출 변동 수식**:
     $$\Delta \text{sales}_i = \text{avg\_sls\_amt}_i - \text{prvyr\_avg\_sls\_amt}_i$$
   - **주의**: 단일 공시서 내에서 본부가 직접 신고한 전년 대비 실적으로, 존속 브랜드에만 국한되며 업종 전체 거시 중앙값 차이와 수학적으로 일치하지 않음.

#### B. 2025년 공정위 데이터(6,519건) 및 2026년 스냅샷(4,521건) 비교 위험 판정 (정정)

| 검토 항목 | 실제 데이터 및 분석 내용 | 위험도 및 판정 결과 |
| :--- | :--- | :---: |

  - 유효한 256개 시군구 중 하나를 선택하면 실제로 격자가 100% 존재하므로 (최소 28개 ~ 최대 1,351개), 정상적으로 원형 격자가 렌더링되고 빈 상태 배너는 사라집니다.

## 11. MVP 범위 (Minimum Viable Product Scope - R3)

사용자의 승인 후 즉시 착수할 **MVP의 범위는 상위 P0 4대 기능**으로 엄격히 한정합니다:

1. **MVP 1: 전국 256개 시군구 지역 선택 및 100m 밀집 격자 동적 연동**
   - 상단 컨트롤 바의 시도/시군구 드롭다운에서 256개 시군구 중 하나를 선택.
   - 백엔드 `/api/v1/spatial/density/grid?sigungu_code={sigungu_code}&limit=1500`를 호출하여 해당 시군구의 실제 100m 격자를 조회하고 지도 레이어에 즉시 교체 렌더링.
   - 지도 중심 좌표가 해당 시군구로 부드럽게 자동 이동 (`map.flyTo`).
2. **MVP 2: 전국 벤치마크(가맹점 6.53% / 브랜드 22.89%) 대비 듀얼 격차 비교 바**
   - 선택 시군구의 침투율을 전국 공식 기준선(가맹점 6.53%, 브랜드 22.89%)과 나란히 비교.
   - 각 지표 하단에 분자(가맹점수/브랜드점포수)와 분모(총점포수)를 명시하여 통계적 오해 차단.
3. **MVP 3: 실측 0건 시에만 진입하는 진정한 Empty State 대응**
   - 광진구에 한정하던 인위적 가상 차단을 완전히 삭제.
   - 256개 시군구는 실제 격자가 100% 표출되며, 전국('00') 뷰포트나 광역 시도 선택 등 실제로 격자 데이터가 0건일 때만 정당한 안내 HUD 표출.
4. **MVP 4: API 메타데이터 기반 동적 출처 배지 표준화**
   - 소진공: API 메타 `data_reference_month`를 반영한 `[소진공 2026-07 공간 전수]` 배지 부착.
   - 공정위: API 메타를 반영한 `[공정위 2026 (2025 실적) 스냅샷]` 또는 `[공정위 2025 (2024 실적) 완결 후보 (공식마감 미확인)]` 배지 부착.

## 12. 예상 위험과 회귀 가능성 (Anticipated Risks & Regressions)

1. **2026 스냅샷(4,521건)과 2025 완결 후보(6,519건)의 표본 왜곡 위험**:
   - *위험*: 2026년 진행형 스냅샷의 표본 미달로 인해 단순 전년비 증감률 산출 시 시장 축소로 오인할 위험.
   - *대책*: 2026년 막대에 단순 증감률(%) 표기를 원천 차단하고 `[진행형 스냅샷: 전년 직접 비교 불가]` 배지 및 툴팁 고정.
2. **제주시(1,351건) 등 1,000건 초과 지역의 격자 잘림 위험**:
   - *위험*: 클라이언트가 `limit=1000` 기본값으로 호출할 경우, 1,351개 격자를 가진 제주시는 351개 격자가 렌더링되지 않는 문제.
   - *대책*: 클라이언트 요청 쿼리에 `limit=1500` (또는 2000)을 명시하여 256개 전 시군구 격자가 100% 누락 없이 서빙되도록 보장.
3. **타 지역 이동 시 잔여 격자 유령 현상 (Ghost Grid Artifact)**:
   - *위험*: 이전 시군구의 격자 피처가 메모리/소스에 남아있어 새 지역 이동 시 엉뚱한 위치에 격자가 잔존하는 현상.
   - *대책*: 시군구 변경 시 즉시 새 FeatureCollection으로 원자적 교체(`source.setData(formatGridToGeoJSON(newItems))`)하고, 로딩 중에는 이전 레이어를 숨기거나 즉시 클리어.
4. **지역 선택 시 불필요한 공정위 API 재호출 회귀 위험**:
   - *위험*: 시도/시군구를 변경할 때마다 우측 공정위 패널이 불필요하게 재호출되어 화면 깜빡임 및 네트워크 낭비 발생.
   - *대책*: `useEffect` 종속성을 분리하여 공정위 API는 `[selectedCategory, selectedYear]`에만 반응하고, 지역 API는 `[activeRegionCode]`에만 반응하도록 완전 격리.
5. **모바일 390×844 레이아웃 오버플로우 회귀 위험**:
   - *위험*: 신규 듀얼 게이지 바나 지역 선택 드롭다운 추가 시 390px 가로 스크롤 발생.
   - *대책*: 모든 신규 컴포넌트에 `box-sizing: border-box`, `max-width: 100%`, `overflow-x: hidden` 적용 및 CDP 실측 자동화 검증.
