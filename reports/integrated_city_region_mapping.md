## 4. 정합성 검증 로직 (Data Contract & Reconciliation)

전국 데이터의 데이터 무결성 원칙(`AGENTS.md`)을 준수하기 위해 다음과 같은 상호 대조 검증 공식을 적용합니다.

### 4.1 정합성 검증 공식
$$\text{Reconciliation Formula: } \sum_{i=1}^{27} \text{totalCount}(\text{signguCd}_i) = \text{totalCount}(\text{ctprvnCd}=12) = 55,881\text{건}$$

* **시도 전체 직접 조회 총계 (`ctprvnCd=12`)**: **55,881건**
* **권역별 점포수 실측 소계**:
  * **옛 광주 5개 자치구**: 동구(2,647) + 서구(4,679) + 남구(2,541) + 북구(5,755) + 광산구(5,861) = **21,483건** (38.4%)
  * **옛 전남 5개 일반시**: 목포(4,434) + 여수(6,060) + 순천(4,932) + 나주(2,025) + 광양(3,069) = **20,520건** (36.7%)
  * **옛 전남 17개 군**: 담양(953) ~ 신안(546) 17개 군 합산 = **13,878건** (24.8%)
* **27개 기초지자체 합산 총계**:
  $$21,483 + 20,520 + 13,878 = \mathbf{55,881\text{건}}$$
* **차이 (Discrepancy)**: **`0건 (100.0% 완전 일치)`**
* **정합성 최종 판정**: **`PASS (데이터 계약 완전 충족)`**
