# Phase 5C-Vis Step 3 개발 지침 — 모바일 필터 접근성 개선

## 1. 목표

- 390×844 모바일 화면에서 상단 필터를 2행 구조로 재배치한다.
- 모든 선택 컨트롤과 버튼의 실제 터치 영역을 최소 44×44px로 확보한다.
- 지도 가시 영역과 기존 데스크톱 UI·데이터 동작을 유지한다.

## 2. 변경 범위

- `frontend/src/components/CategoryFilterBar.jsx`
- `frontend/src/index.css`
- 위 두 파일의 변경으로 직접 깨지는 최소 호출부 또는 검증 자료만 추가 수정한다.

## 3. 구현 지침

1. `768px` 이하에서 필터를 다음 두 행으로 구성한다.
   - 1행: 시도, 시군구, 공정위 연도, 공정위 패널 버튼
   - 2행: 8대 업종과 `기타 외식 (미매핑)` 탭의 가로 스크롤 목록
2. `select`, 업종 탭, 공정위 패널 버튼은 실제 hit area 기준 최소 높이 44px를 적용한다.
3. 기존 `CategoryFilterBar`의 상태·콜백·ARIA 속성과 키보드 조작을 유지한다.
4. 업종 탭은 선택 상태가 화면 밖에 있으면 사용자가 확인할 수 있도록 기존 가로 스크롤 구조 안에서 노출한다. 새 캐러셀 또는 외부 라이브러리는 추가하지 않는다.
5. 필터 확장 때문에 지도 HUD, 범례, 팝업, 공정위 패널의 클릭 영역이 가려지지 않게 한다.
6. 애니메이션을 추가해야 한다면 `transform`과 `opacity`만 사용하고 `prefers-reduced-motion`을 존중한다.
7. 불필요한 `memo`, `useMemo`, `useCallback`, 신규 상태 또는 공통 컴포넌트 추출은 하지 않는다. 프로파일링으로 재렌더 병목이 확인될 때만 적용한다.

## 4. 금지 사항

- `collector.py`, `gangnam_food_stores.sqlite3`, `run_gangnam.bat` 수정 또는 삭제
- 백엔드 API, SQLite 스키마, 데이터 수집·정제 로직 변경
- 8대 대분류·48개 중분류 체계 또는 `CAT_MAJ_99` 의미 변경
- 실제 3D 건물 모델, 그림자 투사, 3D 타일 기능 구현
- 새 npm 의존성 추가
- 기존 Phase 5C-Vis Step 2 보고서와 증빙 파일 덮어쓰기

## 5. 합격 기준

| 시나리오 | 합격 기준 |
|---|---|
| 모바일 390×844 | 필터 2행 배치, 가로 넘침 없음, 모든 조작 요소 44×44px 이상 |
| 모바일 업종 선택 | 첫 탭·중간 탭·마지막 `CAT_MAJ_99` 선택 가능, 선택 상태와 벤치마크 데이터 연동 유지 |
| 모바일 지역/연도 | 시도→시군구 전환 및 연도 자동/직접 지정 동작 유지 |
| 모바일 지도 | 제주시 1,351개 개요 피처와 광진구 466개 조망이 필터에 가리지 않고 유지 |
| 모바일 팝업 | 실제 터치로 열리고 뷰포트 밖으로 잘리지 않음 |
| 데스크톱 1440×900 | 기존 1행 필터 레이아웃과 Step 2 지도 동작 무회귀 |
| 접근성 | 명시적 label/ARIA 유지, 키보드 포커스 식별 가능, 축소 모션 설정 존중 |
| 빌드 | `npm.cmd run build` 성공 |

## 6. 검증 및 증빙

- 390×844 모바일: 기본 화면, 마지막 업종 탭 선택, 지역·연도 선택, 지도 팝업 화면을 각각 캡처한다.
- 1440×900 데스크톱: 기본 화면과 제주시 전체 조망을 회귀 캡처한다.
- 각 조작 요소의 `getBoundingClientRect()` 실측 폭·높이와 가로 오버플로 여부를 JSON으로 저장한다.
- API 수신 건수와 `queryRenderedFeatures`의 고유 격자 수를 분리 기록한다.
- 결과 보고서는 `reports/phase5c_vis_step3_verification_report.md`로 새로 작성하고 기존 보고서를 수정하지 않는다.
