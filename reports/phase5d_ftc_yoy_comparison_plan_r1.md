# Phase 5D: 공정위 완결 후보 연도 전년비 보조 비교 개발 계획서 (R1)

- 작성일: 2026-10-16
- 작업 경로: `D:\Franchise_Dashboard`
- 상태: **계획 수립 완료 / 사용자 승인 대기**
- 선행 조건: Phase 5C-Vis Step 3 Remediation R2 승인 완료
- 준수 기준: `AGENTS.md`, 공정위 Branch C 데이터 계층 분리 정책, 단계별 승인 절차

## 1. 결론

다음 개발 단계는 **기존 공정위 연도별 추세 응답을 재사용하여 2024년과 2025년의 전년비 보조 비교를 추가하는 작업**으로 한정한다.

- 비교 대상: `2024 → 2025`
- 비교 지표: 중위매출, 5% 절사평균, 점포 가중평균 매출, 가맹점 수
- 함께 표시할 값: 각 연도 표본 수와 증감액·증감률
- 2025년 표기: `최신 완결 후보 · 공식 마감 여부 미확인`
- 2026년 표기: `진행형 스냅샷 · 전년 직접 비교 불가`
- 신규 API, DB 스키마, 데이터 수집, 외부 의존성 추가: **없음**

## 2. 선정 근거

1. 지역 내 상위 브랜드 Top 5는 `MarketSummary.jsx`와 지역 상세 API에 이미 구현되어 있으므로 다시 개발하지 않는다.
2. `/api/v1/ftc/trends`는 연도별 비교에 필요한 지표와 표본 수를 이미 제공한다.
3. 따라서 프론트엔드에서 기존 응답의 2024·2025 항목을 찾아 계산하면 목적을 달성할 수 있다.
4. 공정위 고성장 브랜드 Top 5는 평문 브랜드명이 없고, 기존 공식 검증 문서가 가명 ID를 개별 브랜드처럼 순위화하는 UI를 금지하므로 개발 대상에서 제외한다.

## 3. 개발 범위

### 3.1 필수 변경 후보

- `frontend/src/components/FtcBenchmarkPanel.jsx`
  - 기존 `yearly_series`에서 2024·2025 레코드 탐색
  - 지표별 증감액과 증감률 계산
  - 비교 불가 조건 처리
  - 보조 비교 UI와 정확한 상태 문구 추가
- `frontend/src/index.css`
  - 기존 공정위 패널 스타일 체계를 재사용한 최소 스타일 추가
- 기존 프론트엔드 테스트 또는 검증 스크립트
  - 프로젝트의 현재 검증 방식에 맞춰 계산·표시·모바일 회귀 검증 추가
- 실행보고서, 품질검증보고서, 원시 측정 결과

### 3.2 변경하지 않는 대상

- FTC/소진공 수집·정제 파이프라인
- 8대 대분류·48개 중분류 체계
- `collector.py`, `gangnam_food_stores.sqlite3`, `run_gangnam.bat`

- 새 npm 패키지 및 범용 차트 라이브러리

## 4. 계산 및 표시 계약

### 4.1 계산식

- 증감액: `2025 값 - 2024 값`
- 증감률: `(2025 값 - 2024 값) / 2024 값 × 100`
- 소수점 표시는 기존 패널 포맷터를 재사용한다.
- 2024 기준값이 `0`, `null`, 비수치이면 증감률을 계산하지 않고 `비교 불가`로 표시한다.

### 4.2 데이터 조건

- 두 연도가 모두 응답에 존재할 때만 전년비를 표시한다.
- 2025년은 공식 확정치로 표현하지 않는다.
- 2026년 진행형 스냅샷은 계산식과 UI 모두에서 제외한다.
- 업종 필터 변경 시 현재 선택한 8대 대분류의 동일 응답 안에서만 다시 계산한다.
- 소진공 지역 통계와 공정위 전국 거시 통계를 결합하거나 동일 모집단처럼 표현하지 않는다.

### 4.3 UX 원칙

- 기존 연도별 추세 차트 바로 아래에 작은 보조 비교 블록 1개만 추가한다.
- 상승·하락은 색상뿐 아니라 `증가`, `감소`, `변동 없음` 텍스트와 부호로 함께 표시한다.
- 모바일에서 별도 탭이나 새 패널을 만들지 않고 기존 패널 내부에서 세로로 배치한다.
- 비교 기준, 표본 수, 2025년 상태를 한 화면에서 확인할 수 있어야 한다.

## 5. 단계별 작업 계획

### Step 5D-1 — 기준선 및 계산 로직

1. 보호 파일 3종의 해시·크기·수정 시각을 기록한다.
2. 기존 `/api/v1/ftc/trends` 응답에서 2024·2025 데이터 존재 여부와 필드 타입을 확인한다.
3. 컴포넌트 내부에 필요한 최소 계산만 추가한다.
4. 0·결측·연도 누락 시 비교 불가 분기를 검증한다.

완료 조건: 정상·0 기준값·연도 누락 사례의 계산 결과가 명시된 기대값과 일치한다.

### Step 5D-2 — 보조 비교 UI

1. 추세 차트 하단에 비교 블록을 추가한다.
2. 4개 지표의 2024 값, 2025 값, 증감액, 증감률을 표시한다.
3. 양 연도 표본 수와 2025년 상태 문구를 병기한다.
4. 키보드 읽기 순서와 스크린리더용 의미 전달을 유지한다.

완료 조건: 데스크톱과 390×844 모바일에서 잘림·가로 오버플로 없이 모든 정보가 읽힌다.

### Step 5D-3 — 회귀 및 품질 검증

1. 전국·지역 선택, 8대 업종 전환, 연도 선택 동작을 회귀 검증한다.
2. 2026년 스냅샷이 전년비 계산에 포함되지 않았음을 원시 결과로 확인한다.
3. 프론트엔드 빌드와 기존 자동 검증을 실행한다.
4. API·DB·보호 파일 무변경을 해시 및 Git diff로 확인한다.
5. 실행보고서, 품질검증보고서, 원시 측정 데이터를 제출한다.

완료 조건: 필수 항목 전부 PASS이고 근거 파일과 보고서 판정이 일치한다.

## 7. 중단 조건

다음 중 하나가 확인되면 구현을 확대하지 않고 사용자에게 보고한다.

- 2024 또는 2025 원시 데이터가 현재 API 응답에서 누락됨
- 동일 지표의 단위 또는 산식이 연도 간 달라 직접 비교가 불가능함
- 2025 상태를 완결 후보로 볼 수 없다는 새 검증 근거가 발견됨
- 기존 컴포넌트만으로 안전하게 처리할 수 없어 API 계약 변경이 필요함
