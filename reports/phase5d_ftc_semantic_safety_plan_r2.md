# Phase 5D: 공정위 업종 벤치마크 오인 방지 및 의미 안전성 개선 계획서 (R2)

- 작성일: 2026-10-16
- 상태: **정정 계획 수립 완료 / 사용자 승인 대기**
- 대체 대상: `phase5d_ftc_yoy_comparison_plan_r1.md`
- 핵심 원칙: **브랜드 분석과 공정위 업종 벤치마크를 사용자가 혼동하지 않도록 한 뒤 후속 분석 기능을 개발한다.**

## 1. 정정 결론

Phase 5D의 우선 목표를 전년비 기능 추가에서 다음 목표로 변경한다.

> 공정위 패널은 특정 브랜드의 실적이 아니라, 선택 업종에 대한 전국 가맹시장 참고 기준임을 화면 구조·문구·상호작용 전반에서 명확하게 전달한다.

전년비 보조 비교는 오인 방지 검증이 완료된 후 별도 승인을 받아 진행한다.

## 2. 데이터 역할 계약

| 데이터 계층 | 허용 표현 | 금지 표현 |
|---|---|---|
| 소진공 점포 데이터 | 브랜드명, 점포 위치, 지역별 점포 수, 밀집도, 지역 브랜드 순위 | 검증되지 않은 점포를 공식 가맹점으로 단정 |
| 공정위 가명 데이터 | 전국 업종별 매출·창업비용·가맹점 수·연도별 거시 추세 | 특정 실제 브랜드의 매출·비용·성장률로 표현 |
| 두 계층의 병렬 표시 | `지역 브랜드 현황`과 `전국 업종 참고 기준`을 분리하여 함께 제공 | 동일 브랜드 레코드처럼 결합하거나 인과관계로 해석 |

## 3. 개발 범위

### Step 5D-1 — 실제 연동 및 오인 가능성 감사

1. 브랜드·업종·지역 선택에 따라 `FtcBenchmarkPanel`의 제목, 배지, 본문이 어떻게 바뀌는지 확인한다.
2. 다음 오인 가능성을 화면 크기별로 점검한다.
   - 공정위 수치가 선택 브랜드의 실적처럼 보이는가
   - 전국 통계를 선택 지역의 통계처럼 보이게 하는가
   - `공정위`, `전국`, `업종`, `참고 기준`이 첫 화면에서 확인되는가
   - 데이터 연도와 스냅샷 상태가 숨겨져 있지 않은가
3. 데스크톱 1440×900 및 모바일 390×844의 원시 캡처와 측정 결과를 남긴다.

완료 조건: 오인 유발 요소를 파일·화면·문구 단위로 분류한 감사보고서 제출.

### Step 5D-2 — 최소 문구 및 정보구조 수정

감사에서 확인된 문제만 수정한다.

- 패널 대표 제목을 `공정위 전국 업종 벤치마크`로 통일한다.
- 선택 업종명을 포함하되 선택 브랜드명은 공정위 수치의 주어로 사용하지 않는다.
- 패널 상단에 `특정 브랜드 실적 아님` 안내를 항상 노출한다.
- 지역 선택 중에도 `전국 기준`임을 유지한다.
- 소진공 브랜드 카드와 공정위 패널 사이에 데이터 출처와 모집단 차이를 명확히 표시한다.
- 기존 접근성 속성, 모바일 레이아웃, 패널 접기 기능을 유지한다.

완료 조건: 사용자가 패널을 펼친 첫 화면에서 출처·전국 범위·업종 기준·브랜드 비귀속성을 확인 가능.

### Step 5D-3 — 의미 안전성 및 회귀 검증

1. 메가커피 등 실제 브랜드 선택 시 공정위 수치가 해당 브랜드 실적으로 표현되지 않는지 검증한다.
2. 지역 변경 시에도 공정위 수치가 지역 통계로 오인되지 않는지 검증한다.
3. 8대 대분류 전환 시 공정위 업종 매핑과 제목이 일치하는지 확인한다.
4. 전국·지역·브랜드·업종 선택 조합을 자동 또는 반자동 시나리오로 검증한다.
5. 프론트엔드 빌드, 모바일 오버플로, 키보드 접근성, 기존 지도 기능을 회귀 검증한다.
6. 실행보고서, 품질검증보고서, 원시 측정 자료를 제출한다.

완료 조건: 필수 시나리오 전부 PASS이고 보고서와 원시 근거가 일치.

## 4. 필수 인수 기준

| ID | 항목 | 합격 기준 |
|---|---|---|
| S-01 | 패널 정체성 | 제목에 `공정위`, `전국`, `업종 벤치마크` 의미가 명확함 |
| S-02 | 브랜드 비귀속 | `특정 브랜드 실적 아님`이 패널 첫 화면에 항상 노출됨 |
| S-03 | 지역 비귀속 | 지역 선택 후에도 전국 기준임을 명시함 |
| S-04 | 출처 분리 | 소진공 점포 분석과 공정위 거시 통계의 출처·모집단을 구분함 |
| S-05 | 실제 브랜드 시나리오 | 메가커피 선택 시 공정위 수치가 메가커피 실적으로 읽히는 문구 0건 |
| S-06 | 가명 보호 | 가명 ID를 실제 브랜드명으로 추정·변환·순위화하지 않음 |
| S-07 | 반응형 | 1440×900 및 390×844에서 핵심 안내가 잘리거나 숨지 않음 |
| S-08 | 접근성 | 안내 문구와 상태가 시각·텍스트·스크린리더에서 전달됨 |
| S-09 | 회귀 | 지도, 필터, 지역 브랜드 Top 5, FTC 연도 선택 기능 정상 |
| S-10 | 보호 자산 | 보호 파일·DB·수집 파이프라인 변경 0건 |

1. **현재 승인 대상:** Step 5D-1 실제 연동 및 오인 가능성 감사
