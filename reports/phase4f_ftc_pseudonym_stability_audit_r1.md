# Phase 4F 공정위 가명 식별자(Pseudonym ID) 연도간 안정성 감사 보고서 (R1 정정본)

## 1. 감사 개요 및 목적

공정거래위원회 가맹사업정보 공공 API는 브랜드명과 본부명을 평문 대신 단방향 가명 식별자(`alsBrandMngNo`, `alsJnghqMngNo`)로 제공합니다.

본 R1 감사의 목적은 다음과 같습니다:
1. **연도 간 가명 식별자의 재관측 패턴 검증**: 가명 브랜드 ID가 연도가 바뀌어도 동일 브랜드를 시계열로 추적할 수 있는지 연도 간 지속성(Persistence) 패턴 전수 검증
2. **가명 본부 ID의 연도 간 변동성 감사**: 동일 브랜드에 매핑된 가명 본부 ID의 연도 간 변경 현황 분석 및 원천 식별체계 변경 가능성 고찰
3. **미관측 브랜드 지표의 엄격한 정의**: 당해연도 미관측 데이터를 폐업이나 이탈로 단정하지 않고, `전년 존재·당해연도 미관측` 지표로 정정하여 통계적 왜곡 차단
4. **존속 브랜드 균형 패널(Balanced Panel) 비활성화 유지**: 생존편향(Survivorship Bias) 내포 위험에 따라, 패널 분석 엔진 활성화 및 대시보드 연동은 **사용자의 별도 승인 전까지 엄격히 비활성 상태로 유지**

## 3. 핵심 발견 및 R1 정정 감사 소견

### 3.1 발견 1: 브랜드 가명 ID(`alsBrandMngNo`)의 연도 간 재관측 패턴 확인
- **81% ~ 83%의 높은 연간 지속성 관측**:
  - 2023년에서 2024년으로 넘어갈 때 81.44%(4,990개), 2024년에서 2025년으로 넘어갈 때 83.07%(5,252개)의 브랜드 가명 ID가 동일하게 재관측되었습니다.
  - 이는 공정위 API 상에서 브랜드 가명 식별자가 매년 무작위 난수로 재생성되는 것이 아니라, **다년간 일정하게 유지되는 재관측 패턴이 존재함**을 확인해 줍니다.
  - *(정정 반영)*: 공식 암호화 명세서나 솔트 생성 규칙에 관한 공공 문서가 부재하므로, 종전 보고서의 "고정 솔트 사용을 기술적으로 입증했다"는 단정적 표현은 배제하고, "연도 간 재관측 패턴이 통계적으로 관측된다"는 엄격한 표현으로 정정합니다.

### 3.2 발견 2: 2024→2025년 본부 가명 ID 전면 변경 현상 관측
- **2024→2025년 구간 본부 가명 ID 변경률 100.0%**:
  - 2023→2024년 구간에서는 본부 가명 ID 변경률이 7.49%, 2025→2026년 구간에서는 4.29%로 낮은 수준을 보였습니다.
  - 그러나 **2024년에서 2025년으로 넘어갈 때, 지속 관측된 5,252개 브랜드의 본부 가명 ID(`alsJnghqMngNo`)가 100.0% 전부 변경**된 현상이 확인되었습니다.
  - *(정정 반영)*: 종전 보고서의 "법인 전환/양수도 때문"이라거나 "시스템 개편으로 암호화 솔트가 변경되었음을 규명했다"는 단정을 배제합니다.
  - 대신 **`2024→2025 구간에서 본부 가명 ID가 전부 달라져 가명화 정책 또는 원천 식별체계 변경 가능성이 관측되며, 공식 문서가 없으므로 구체적 원인은 확정할 수 없음`**으로 공식 정정합니다.
  - **시사점**: 연도 간 시계열 종단면 조인 시 본부 가명 ID를 결합하면 2024→2025년 연계가 완전히 단절되므로, 향후 패널 구성 시에는 오직 `alsBrandMngNo`만을 단독 연결키 후보로 고려해야 합니다.

### 3.3 발견 3: "미관측(Unobserved)" 지표의 엄격한 정의 및 폐업률 산출 금지
- **"전년 존재·당해연도 미관측" 지표 확정**:
  - 2025→2026년 구간의 미관측 수치(2,765개)를 "이탈" 또는 "폐업"으로 표현하던 종전 방식을 전면 금지합니다.
  - 본 수치는 **실제 폐업, 가맹사업 종료, 가맹본부의 정보공개서 정기변경등록 지연, 공정위의 2026년 최신 스냅샷 미반영 등이 복합적으로 혼재**되어 있으며, 현재 제공되는 API 데이터만으로는 이를 상호 분리하여 식별할 수 없습니다.
  - 따라서 **2026년 자료를 기반으로 폐업률이나 브랜드 이탈률을 임의로 산출하지 않으며**, 해당 지표는 오직 `전년 존재·당해연도 미관측`으로만 명명합니다.

## 4. 존속 브랜드 균형 패널(Balanced Panel)과 생존편향 주의사항

### 4.1 4개년 연속 관측 브랜드(균형 패널) 규모
- **4개년(2023, 2024, 2025, 2026) 모두 존재하는 브랜드**: **2,504개**
  - 2023년 전체 브랜드 모수(6,127개) 대비: **40.87%**
  - 2026년 현재 등록 브랜드 모수(4,515개) 대비: **55.46%**
- **과거 미관측 후 재등장(Reappearing) 브랜드**: 274개 (2025년 160개 + 2026년 114개)

### 4.2 생존편향(Survivorship Bias) 발생 메커니즘 명시

> [!CAUTION]
> **균형 패널 분석 시 생존편향 주의 경고**:
> 4개년 연속 관측 브랜드만을 추려서 분석하는 기법은 "생존편향을 제거"하는 것이 아닙니다.
> **오히려 4년간 폐업하지 않고 지속 영업한 우량 브랜드만 선택(Selection Bias)되므로 강력한 통계적 생존편향이 내포**됩니다.

1. **모집단과의 괴리 및 왜곡 가능성**:
   - 신규·미관측 브랜드가 제외되므로 전체 모집단과 다른 방향 또는 크기로 왜곡될 가능성이 있습니다.
2. **용어 및 정책 확정**:
   - 본 분석은 "생존편향 제거 분석"으로 표기할 수 없으며, 반드시 **`존속 브랜드 균형 패널 (4개년 연속 관측 2,504개 브랜드)`**로 명명합니다.
   - 대시보드 제공 시에는 **반드시 [전체 모집단 횡단면 추세]를 기본 뷰로 제공**해야 합니다.
