## 1. 확인된 정상 항목

- 데스크톱 히어로에 `전국 가맹본부 대표매출 (중앙값)`과 특정 브랜드·개별 점포 실적이 아니라는 안내가 실제 노출된다.
- 모바일 피크 바에 `공정위 전국`, 억 단위 중위값, `업종 참고치`가 노출된다.
- 모바일 확장 첫 화면에 전국 거시 벤치마크 안내가 노출된다.
- 2026 진행형 스냅샷 경고가 호버 없이 노출된다.
- `phase5d_step2_validation.json`은 UTF-8 기준 유효한 JSON이며 Node `JSON.parse`에 성공한다.
- `npm.cmd --prefix frontend run build` 재실행 결과 빌드에 성공했다. 기존 500 kB 초과 청크 경고는 남아 있다.
- 보호 파일 3종의 현재 SHA-256이 보고서 기준값과 일치한다.

## 2. 승인 차단 결함

### F-01. 전국 시나리오가 실제로는 서울특별시 광진구에서 실행됨

- S1, S3, S4 캡처의 지역 선택기는 `서울 / 서울특별시 광진구`를 표시한다.
- S5는 S4 상태를 이어받으므로 동일한 지역 상태다.
- `App.jsx`의 초기값도 `selectedSido='11'`, `selectedSigungu='11215'`이다.
- 검증 스크립트는 S1·S3·S4·S8에서 `resetAndNavigate()` 후 `selectRegion('00', '')`를 호출하지 않는다.
- 그럼에도 원시 JSON의 `conditions.region`과 실행보고서는 해당 시나리오를 `전국`으로 기록한다.

따라서 현재 `8/8 PASS`, `overallPass: true`, JSON·PNG·보고서 일치 주장은 신뢰할 수 없다. 문구 개선 자체는 확인되지만, 승인 기준인 시나리오 재현성과 증빙 일관성을 충족하지 못했다.

### F-02. 지역 조건을 검증하는 단언이 없음

S1·S3·S4·S5·S8의 PASS 조건은 공정위 패널 문구와 가시성만 확인한다. 실제 `#sido-select`, `#sigungu-select`의 value/text를 측정하거나 기대 조건과 비교하지 않아 F-01을 탐지하지 못했다.
