대한민국 외식 프랜차이즈 3D GIS 상권 분석 대시보드

전국 735,185개 고유 외식업 점포 전수 조사 데이터와 공정거래위원회 4개년(2023~2026) 거시통계를 결합하여, 상권의 과밀도와 브랜드 경쟁 현황을 3차원으로 분석하는 시스템의 공식 사용자 설명서입니다.

1. 시스템 개요 및 기획 의도

대한민국 외식업은 매년 10만 건에 육박하는 폐업이 발생하며, 신규 창업자의 3년 내 생존율이 40% 미만으로 떨어지는 위기를 겪고 있습니다. 그 주된 원인은 '단편적인 2D 평면 지도'와 '주관적인 감(Intuition)'에만 의존해 억대 자본을 투자하기 때문입니다.

💡
기획 의도: 왜 3차원 공간 인텔리전스인가? 평면 지도에서는 점포들이 한곳에 점으로 겹쳐 표시되어, 실제 그 골목의 경쟁 강도가 얼마나 치열한지 체감하기 어렵습니다. 본 대시보드는 100m 정밀 격자 3D 기둥(`fill-extrusion`)의 높이로 경쟁 과밀도를 입체화하고, 공정거래위원회의 실제 가맹점 평균 매출과 창업비용을 1:1 대사하여 실패 없는 의사결정을 돕습니다.

시스템 핵심 4대 지표

✓

전국 735,185개 외식 점포 전수 조사

소상공인진흥공단 공공데이터를 기반으로 결측치 0% 자동 무결성 검증을 통과한 대한민국 외식업 전수 데이터베이스.

✓

16개 광역시도 & 256개 시군구 전역 커버

서울 강남구부터 제주 서귀포시까지 전국 모든 행정구역의 다차원 시장 침투율 및 업종 점유율 완벽 집계.

✓

5,063개 브랜드 정밀 대사 (Decoupled State Model)

전국 10개 이상 점포 클러스터링 알고리즘을 통해 일반 개인 음식점과 공인 프랜차이즈를 100% 분리하여 통계 왜곡 원천 차단.

✓

공정거래위원회 4개년(2023~2026) 거시통계 결합

브랜드별·업종별 실측 평균 매출액, 평당 인테리어비, 가맹금, 보증금 시계열 횡단면 데이터 융합 제공.

2. 📚 초보자를 위한 핵심 용어 & 약어 사전

시스템에서 사용하는 전문 기술 용어와 약어를 초보자도 한눈에 알기 쉽게 정리했습니다. 처음 사용하시는 분은 이 사전을 먼저 읽어보시면 대시보드를 훨씬 직관적으로 이해하실 수 있습니다.

약어 · 공공기관

FTC (공정거래위원회)

Fair Trade Commission의 약칭입니다. 프랜차이즈 가맹본부가 법적으로 의무 제출하는 정보공개서(창업비용, 평균 매출액, 가맹점수)의 공식 출처입니다.

공간 기술 · 지도

BBOX (Bounding Box, 뷰포트 사각형)

지도를 볼 때 현재 내 모니터 화면에 나타나는 지도의 사각형 영역을 뜻합니다. 73.5만 개 데이터를 한 번에 다 불러오면 컴퓨터가 멈추므로, 내가 확대해서 보고 있는 BBOX 안의 점포만 실시간으로 받아옵니다.

3D 시각화 기술

fill-extrusion (3D 기둥 돌출)

평면 지도 위의 100m 격자를 점포 밀집도에 따라 위로 솟아오르게 만드는 3D 그래픽 기법입니다. 기둥이 높을수록 해당 블록에 경쟁 점포가 빽빽하게 모여 있음을 의미합니다.

통계 지표

YoY (전년 대비 증감률)

Year-over-Year의 약어로, 작년 같은 기간 대비 올해 매출액이나 점포수가 몇 % 늘었거나 줄었는지를 나타내는 시계열 성장 지표입니다.

데이터 아키텍처

Decoupled State Model (분리 대사 모델)

일반 개인 식당(독립점포)과 10개 이상 점포를 가진 공인 프랜차이즈 브랜드를 완전히 분리하여 관리하는 데이터 정제 방식입니다. 가짜 프랜차이즈가 통계에 섞이는 것을 방지합니다.

시장 분석 지표

프랜차이즈 침투율 (%)

특정 행정구역(시군구)의 전체 외식업 점포 중 공인 가맹 프랜차이즈 점포가 차지하는 비율입니다. 침투율이 높을수록 대기업 브랜드 위주의 상권이며, 낮을수록 개인 식당이 많은 상권입니다.

공간 분석 단위

100m 정밀 격자 (Hexagon / Grid)

넓은 행정동 단위를 넘어, 가로세로 100m 크기로 지도를 쪼개어 세밀하게 점포 수를 집계하는 분석 단위입니다. 한 걸음 차이로 갈리는 골목 상권의 진실을 보여줍니다.

UI 컴포넌트

SlimMapRail (우측 슬림 제어 레일)

지도 화면 우측에 부착된 44px 폭의 미니멀 플로팅 조작 바입니다. 지도를 가리지 않으면서 3D 시점 전환, 기둥 높이 켜기/끄기, 색상 모드, 드론 투어 등을 원클릭으로 조작합니다.

3. 빠른 시작 및 접속 가이드

Franchise Dashboard는 공식 클라우드 웹사이트에 상시 배포되어 있어, 별도의 설치 없이 브라우저에서 바로 사용하실 수 있습니다.

🌐
공식 라이브 웹 서비스 (원클릭 즉시 접속) 공식 웹사이트 주소: https://franchise-dashboard-scpz.onrender.com/
PC와 태블릿, 모바일 브라우저에서 프로그램 설치 없이 즉시 전국 73.5만 개 외식업 3D 상권 지도를 이용하실 수 있습니다.

로컬 개발 환경 직접 실행 (개발자 및 오프라인용)

1

실행환경 사전점검 (Preflight Check)

Python 3.12 가상환경, 5대 SQLite 데이터베이스 스키마 및 공정위 4개년 연도 무결성을 1초 만에 자동 검증합니다.

scripts\check_env.bat 실행 → 모든 검사 [PASS] 확인

2

로컬 백엔드 API 서버 기동

FastAPI 고성능 비동기 API 서버를 구동합니다.

scripts\run_backend.bat 실행 → http://127.0.0.1:8000 기동 확인 (Swagger API 문서: /docs)

3

로컬 프론트엔드 대시보드 실행

React + MapLibre GL JS 대시보드 개발 서버를 로컬에서 구동할 수 있습니다.

scripts\run_frontend.bat 실행 → 로컬 브라우저에서 http://localhost:5173 접속

⚡
테스트 스위트 전수 검증 시스템 무결성을 확인하고 싶다면 scripts\run_tests.bat을 실행하세요. API 클라이언트부터 브랜드 마스터까지 82개 단위/통합 테스트가 100% 합격(PASS)하는 것을 확인하실 수 있습니다.

4. 전체 화면 인터페이스 구성

대시보드 화면은 정보 탐색의 편의성을 위해 5대 핵심 영역으로 직관적으로 구성되어 있습니다.

인터페이스 영역 소스 컴포넌트 기능 및 역할
상단 헤더 Header.jsx 전국 16개 시도 및 256개 시군구 선택 드롭다운, 데이터 기준월 안내, 새로고침.
업종 필터 바 CategoryFilterBar.jsx 확정 8대 대분류(한식, 카페, 치킨 등) 원클릭 필터링 및 지도 색상 동기화.
3D GIS 메인 맵 MapContainer.jsx 100m 정밀 격자 3D 기둥 표출, 줌 14+ 개별 점포 스트리밍 마커 및 팝업.
우측 슬림 제어 레일 SlimMapRail.jsx 3D/2D 시점 전환, 기둥 렌즈 On/Off, 색상 테마 전환, 공정위 드로어 토글.
공정위 벤치마크 패널 FtcBenchmarkPanel.jsx 우측 슬라이딩 패널. 4개년 YoY 매출 성장률, 창업비용 5대 요소 실측 벤치마크 제공.

1

3D 경사각 / 2D 평면 탑뷰 토글

지도를 52도 각도로 기울여 3D 입체 기둥의 높낮이를 체감하거나, 위에서 똑바로 내려다보는 2D 평면 탑뷰로 즉시 전환합니다. 기둥 높이를 볼 때는 3D, 정확한 도로망을 볼 때는 2D를 선택하세요.

2

3D 기둥 렌즈 (`fill-extrusion`) 켜기/끄기

100m 격자 기둥의 높낮이를 On/Off 합니다. 기둥 뒤에 가려진 개별 점포 마커를 명확히 보고 싶을 때 기둥 렌즈를 끄면 쾌적한 평면 점포 지도로 바뀝니다.

3

색상 모드 전환 (밀집도 vs 업종별)

기둥의 색상을 '전체 점포 과밀도(Density Heatmap)' 기준에서 선택된 '8대 업종별 고유 테마 컬러'로 전환하여 업종별 분포를 직관적으로 비교합니다.

4

상권 핫스팟 드론 비행 투어 (`Drone Tour`)

강남역, 홍대입구, 명동 등 선택된 지역의 최고 핫스팟 상권으로 카메라가 활강하며 시네마틱 3D 뷰로 비행합니다.

5

Zoom 14+ 개별 점포 스트리밍

지도를 마우스 휠로 확대하여 줌레벨 14에 도달하면 실제 개별 매장 마커들이 화면에 나타나며, 마커를 클릭하면 상호명, 도로명 주소, 가맹 여부를 팝업으로 즉시 확인할 수 있습니다.

7. 공정위 창업비용 벤치마크 활용법

우측 SlimMapRail의 공정위 버튼을 누르면 열리는 FtcBenchmarkPanel은 공정거래위원회 4개년(2023~2026) 실측 정보공개서를 바탕으로 가맹점 평균 매출과 실제 창업비용을 제공합니다.

창업비용 5대 요소 명세

  • 가맹비(가입비): 브랜드 상표권 사용 및 초기 영업 노하우 전수 비용.
  • 계약이행보증금: 물품대금 채권 확보를 위한 예치금 (계약 종료 시 100% 반환).
  • 교육비: 조리, 매장 운영, 고객 서비스 사전 필수 교육 비용.
  • 인테리어 비용: 매장 면적(평당)에 비례하는 바닥/벽면/조명 시공비.
  • 기타 설비비용: 주방 집기, POS 시스템, 간판 등 필수 하드웨어 비용.

8. 상황별 실전 활용 매뉴얼 (3대 시나리오)

CASE 1. 예비 창업자: 과밀 레드오션 회피 및 안전 출점

1

시군구 선택 & 3D 기둥 렌즈 활성화

상단 헤더에서 창업 희망 시군구(예: 서울 마포구)를 선택하고 3D 기둥 렌즈를 켭니다.

2

붉고 높은 기둥(과밀 격자) 회피

100m 격자 기둥이 붉게 솟아있는 곳은 동종 업종 경쟁이 포화된 곳이므로 우선적으로 피합니다.

3

줌인(Zoom 14+)을 통한 반경 500m 실측

지도를 확대하여 후보 상가 반경 500m 이내에 경쟁 브랜드 점포가 몇 개나 있는지 직접 스트리밍 마커로 확인합니다.

4

공정위 벤치마크로 투자금 회수 기간 계산

FTC 패널을 열어 동종 업종의 실제 평균 매출과 인테리어 비용을 검증하고 자본금 소진 리스크를 차단합니다.

CASE 2. 가맹본부 전략팀: 전국 출점 공백지(블루오션) 선점

1

전국 256개 시군구 침투율 비교

수도권 외 광역시 및 주요 시군구의 자사 브랜드 침투율을 경쟁 브랜드와 교차 대조합니다.

2

출점 공백지(Blue Ocean) 필터링

인구 밀도가 높지만 자사 브랜드가 아직 진입하지 않은 격자 포켓을 공간 집계 데이터로 찾아냅니다.

3

가맹점 영업권 보호 반경 시뮬레이션

신규 후보 점포와 기존 가맹점 간의 거리를 3D 공간에서 측정하여 가맹사업법상 영업지역 침해 분쟁을 방지합니다.

CASE 3. 상권 분석가 & 투자자: VIP 고객 투자 브리핑

1

핫스팟 드론 비행 투어로 몰입감 극대화

회의실 대형 화면에서 대상 빌딩 상권으로 부드럽게 하강 비행하는 드론 카메라로 클라이언트의 이목을 집중시킵니다.

2

8대 업종 순환 주기 및 결핍 업종 분석

해당 상권에 카페가 과포화인지, 베이커리나 이색 양식 수요가 비어있는지 100m 기둥 테마로 진단합니다.

3

4개년 시계열 횡단면 데이터 인용

73.5만 건 전수 데이터와 4개년 공정위 통계로 뒷받침된 정밀 투자 의사결정 보고서를 작성합니다.

9. 자주 묻는 질문 (FAQ)

Q1

지도를 확대했는데 개별 점포 마커가 보이지 않아요.

개별 점포 레이어는 브라우저 성능 최적화를 위해 줌레벨 14 이상에서만 실시간 BBOX 스트리밍됩니다. 지도를 더 확대해 보세요.

Q2

3D 기둥 때문에 특정 매장이 가려져서 클릭하기 힘들어요.

우측 SlimMapRail의 [3D 기둥 렌즈] 버튼을 누르면 기둥이 사라지고 평면 점포 지도로 전환되어 시야가 완전히 확보됩니다.

Q3

백엔드 API 연결 오류가 발생합니다.

FastAPI 서버가 구동 중인지 확인하세요. 터미널에서 scripts\run_backend.bat을 실행하고, 브라우저에서 http://127.0.0.1:8000/docs가 열리는지 확인하십시오.

Q4

공정위 벤치마크 데이터의 기준 연도는 언제인가요?

공정거래위원회에 정식 등록된 2023년부터 2026년까지의 4개년 최신 시계열 횡단면 데이터를 제공하고 있습니다.
